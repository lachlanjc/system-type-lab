# System Type Lab

A tiny Vite + React site for exploring system font families and variation axes with DialKit.

## Run locally

```sh
pnpm install
pnpm run dev
```

Click the large specimen to edit its text directly. Use DialKit to change the family, variable width (`wdth`), weight (`wght`), optical size (`opsz`) or automatic optical sizing, font features, classic size and spacing controls, and colors. The Copy CSS and Copy Tailwind classes buttons export the current settings. DialKit controls are saved in your browser.

Variation axis support depends on the font selected by your browser and operating system, so some axes may have little or no visible effect on some devices.
